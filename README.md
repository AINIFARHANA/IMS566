**Lunara Clinic Management System**
Project Description: Lunara Clinic Management System is a web-based application designed to help manage clinic operations efficiently. The system provides an organized interface for patients and clinic staff to access clinic services, view information, manage appointments, and handle billing-related tasks.

**Features Included**
- User Registration Page
- User Login Page
- Dashboard Interface
- Appointment Management
- Patient Management
- Doctor Management
- Billing Management
- Responsive Design
- Navigation Menu
- Form Validation
- User-Friendly Interface
